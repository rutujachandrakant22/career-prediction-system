# Career Path Prediction and Guidance System

## 📌 Problem Statement
This project predicts career paths for students based on their skills, interests, and academic performance using Machine Learning and Deep Learning models. It provides personalized career recommendations and suggested courses.

## 📌 Overview
This project predicts suitable career paths based on user input and recommends relevant courses.  
It uses **Machine Learning, Deep Learning, and Streamlit** for interactive career guidance.

## ⚙️ Installation
Clone the repository:
git clone https://github.com/rutujachandrakant22/career-prediction-system.git
cd career-prediction-system
Install dependencies:pip install -r requirements.txt

## 🎯 Objectives
- Predict the best career paths for students.
- Provide career advice based on skills and interests.
- Evaluate model performance using metrics.
- Deploy the system as a Streamlit application.

## 🚀 Usage
Run the Streamlit app:streamlit run app.py

## 📊 Dataset
File: PS2_Dataset.csv
Contains features used for career prediction.

## 🧠 Models
Random Forest Classifier
Neural Network (TensorFlow/Keras)
Comparison of models for accuracy and performance.

## ⚙️ Workflow
1. Load and preprocess dataset.
2. Perform Exploratory Data Analysis (EDA).
3. Train ML (Random Forest) and DL (Neural Network) models.
4. Evaluate models with accuracy and confusion matrix.
5. Integrate best model into Streamlit app.
6. Provide career predictions and course recommendations.
